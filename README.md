# Homebrew tap pour Kairos

Kairos est un chronomètre de barre de menus pour macOS (Monday). Code source : [LucasRaffalli/kairos](https://github.com/LucasRaffalli/kairos).

```bash
brew install --cask lucasraffalli/kairos/kairos
```

Apple Silicon uniquement. L'app se met à jour toute seule ; ce tap ne sert qu'à la première installation.

La cask (`Casks/kairos.rb`) est générée par `npm run deploy` dans le dépôt de Kairos : ne pas la modifier à la main.
